# infrastructure/docker

**Status: implemented (Milestone 1).** `compose.yaml` runs postgres, redis (Redis Stack, `noeviction`, AOF, password), minio, api, worker, ai-engine and web, each with a healthcheck, plus an optional `observability` profile (Grafana OTLP stack). Dockerfiles are multi-stage and run as non-root. Start with `pnpm stack:up` after `./scripts/setup-local-env.sh`. Run migrations with the one-off `migrate` service (`--profile tools`), which is the only place the owner credentials are used. The MinIO image is a frozen legacy mirror (dev only, see CURRENT.md). Compose is also the reference topology for the future customer-hosted bundle ([docs/architecture/deployment-models.md](../../docs/architecture/deployment-models.md)).
